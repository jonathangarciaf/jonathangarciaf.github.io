# img/photography/

Everything here is private working material (git-ignored) except `web/`.

- `originals/` — untouched full-resolution archive copies
- `review/classification.csv` — numbering 01–74 and country labels
- `edits/NN/` — three versions of photo NN: `NN-original`, `NN-natural`, `NN-bw`,
  plus `NN-compare.jpg`; `edits/overview-*.jpg` show 8 photos per sheet
- `make_versions.py` — regenerates the edits (metadata/GPS not copied)
- `web/` — the chosen versions, published and listed in `/photography.js`
